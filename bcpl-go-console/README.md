# bcpl-go-console

Go port of the coroutine-enabled BCPL INTCODE interpreter from `bcpl-c-console/new_coroutines`.

## Run

From this folder:

```sh
go run . ..\bcpl-c-console\new_coroutines\TEST2
go run . ..\bcpl-c-console\new_coroutines\RUNABLE
```

You can also pass `-iINPUT` and `-oOUTPUT` options, matching the original interface.
